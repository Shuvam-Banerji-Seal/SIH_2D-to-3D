Run it yourself

git clone --recurse-submodules https://github.com/Shuvam-Banerji-Seal/SIH_2D-to-3D
cd SIH_2D-to-3D
uv sync --all-extras
uv run drone3d ui        # console + 3D explorer at http://127.0.0.1:8080
Needs an NVIDIA GPU and uv. The film shows our own runs on public sample footage.
